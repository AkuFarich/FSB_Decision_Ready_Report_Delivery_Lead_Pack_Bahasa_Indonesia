# Paket Ketua Pengiriman — Perintah Kerja AR-2026-082

Paket ini merupakan implementasi acuan lengkap untuk mendemonstrasikan dan meninjau alur kerja pelaporan yang realistis. Sajikan kegiatan sebagai permintaan pengiriman bisnis, bukan sebagai rangkaian pelajaran.

## Urutan pelaksanaan
1. Baca `DELIVERY_LEAD_GUIDE.md`.
2. Mulai dengan `PROJECT_BRIEF.md`.
3. Demonstrasikan alur kerja lengkap mulai dari kontrak masukan sampai serah-terima kepada peninjau.
4. Simpan folder `reference/` secara tertutup selama pengerjaan mandiri; folder tersebut dapat dibagikan setelahnya sebagai implementasi acuan.
5. Tinjau hasil menggunakan `REVIEW_SCORECARD.md`.

Paket acuan berisi kode pembuat laporan yang sudah lengkap, isi yang telah disetujui, laporan yang telah dihasilkan, bukti kegagalan, dan hasil verifikasi yang diharapkan.
